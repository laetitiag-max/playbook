🔍 Étape 1

Valider son sujet avant de produire

La règle d'or : ne jamais produire une formation complète sans avoir validé que des gens veulent l'acheter. Une mini-validation en 48h vaut mieux que 3 semaines de travail sur le mauvais sujet.

Les 5 questions à se poser

  • 1
    Est-ce que mon public cible cherche activement une solution à ce problème ?
  • 2
    Est-ce qu'il existe déjà des formations sur ce sujet ? (Si oui → bonne nouvelle, le marché existe)
  • 3
    Quelle est ma valeur ajoutée par rapport à ce qui existe déjà ?
  • 4
    Mon public connaît-il le nom de la méthode ou cherche-t-il le problème qu'elle résout ?
  • 5
    Est-ce que je peux parler de ce sujet avec crédibilité ou expérience ?
⚡ Validation en 48h

Le sondage LinkedIn en 10 minutes

Avant de produire quoi que ce soit, poste ce type de sondage dans les groupes Facebook ou sur LinkedIn :

Exemple de post de validation
Sondage rapide pour les entrepreneurs et freelances 👇

Tu connais la méthode [NOM] ?

A) Oui, je la pratique au quotidien
B) J'en ai entendu parler mais je ne l'applique pas
C) Jamais entendu parler

Et surtout : quel est TON plus grand problème avec [thème général] ?
👇 dis-moi en commentaire

Comment interpréter les résultats

✅ Majorité A → Parfait Le marché est éduqué, tu peux vendre directement sur le nom de la méthode.
⚡ Majorité B → Opportunité Les gens savent que ça existe mais ne l'appliquent pas. Ton angle = "enfin une formation qui rend GTD simple et applicable".
🔄 Majorité C → Pivote le nom Ne vends pas "la méthode X" mais le problème qu'elle résout. Ex: au lieu de "Formation GTD", → "Comment vider ton cerveau et ne plus rien oublier".
❌ Erreurs à éviter
Erreur 1 — Choisir un sujet sans validation Peu importe si tu es passionné, vérifie toujours que quelqu'un est prêt à payer pour ça.
Erreur 2 — Attendre d'avoir tout parfait pour tester Lance en bêta avec 5 personnes à prix réduit. Les retours réels valent 10x plus que tes suppositions.
Erreur 3 — Ignorer la concurrence Si personne ne vend ce sujet, ce n'est pas une opportunité — c'est un signal d'alarme.

Le pipeline de production

Pour chaque formation, tu suis toujours ce pipeline dans cet ordre exact. Ne saute pas d'étape.

1
Upload des sources dans NotebookLM
Charge tous tes PDFs, livres, articles sur le sujet. Minimum 3 sources solides. Plus tu as de sources de qualité, meilleure sera la formation générée.
📁 NotebookLM
2
Cadrage — Carte mentale + Briefing
Lance le Résumé Audio Briefing pour une vue macro. Génère la Carte Mentale pour valider la structure de ta formation. Ne commence pas à écrire sans cette étape.
🗺️ Carte Mentale + Audio Briefing
3
Intégration du prompt principal
Colle le prompt V4 (avec système de modes) dans les Instructions Personnalisées de NotebookLM. Vérifie que les deux modes fonctionnent avant de commencer.

Demande au Chat de générer le plan complet : titre, promesse, liste des modules avec objectifs et durées. Valide-le avant de produire les modules.

✍️ 1 module = 1 demi-journée

Pour chaque module : podcast → infographie → slides → fiche d'apprentissage. Toutes les sources cochées + prompt précis = meilleur résultat.

✅ Checklist module complet

Ce qui constitue un module 100% prêt

  • ✓
    Texte complet du module (6 sections : accroche, concept, outils, erreurs, cas pratique, défi, quiz, transition)
  • ✓
    Podcast audio généré via NotebookLM (Analyse approfondie ou Briefing selon complexité)
  • ✓
    Infographie PNG générée et uploadée sur Cloudinary
  • ✓
    Présentation slides générée et uploadée sur Google Drive
  • ✓
    Fiche d'apprentissage générée (intégrée dans la webapp)
  • ✓
    Quiz testé personnellement (toutes les questions + corrections)
  • ✓
    Défi formulé en 4 temps (contexte, consigne, résultat attendu, conseil)
  • ✓
    Badge nommé et intégré dans la webapp
  • ✓
    Transition vers le module suivant rédigée
❌ Erreurs à éviter
Erreur 1 — Produire tous les modules avant de tester Fais lire le module 1 à 3 personnes avant de continuer. Leurs retours peuvent changer toute ta structure.
Erreur 2 — Trier ou analyser pendant la capture Lors de la phase de génération NotebookLM : laisse tout sortir, tu affineras après.
Erreur 3 — Perfectionner indéfiniment 80% lancé > 100% jamais publié. Le bêta-test donne les vrais retours, pas ton perfectionnisme.
💡 Règle d'or — 1 module par demi-journée Au-delà, la qualité baisse. Ton cerveau a besoin de pauses entre les modules pour garder de la créativité.
💬 Prompt Principal

Instructions personnalisées NotebookLM

Colle ce prompt dans Instructions personnalisées de ton NotebookLM avant de commencer. Il active le système de deux modes automatiques.

Prompt V4 — Système de modes
Tu as deux modes. Détecte automatiquement lequel utiliser
sans que j'aie besoin de le préciser.

MODE CRÉATION → uniquement si ma demande contient
"crée le module", "génère le module" ou "nouveau module".
Tu suis alors la structure complète en 6 sections.

MODE COACH → pour toute autre demande.
Tu es mon partenaire expert, direct et bienveillant.

Règles du MODE COACH :
- Réponds uniquement à ce qui est demandé
- Zéro introduction inutile : va droit au but
- Adapte ta réponse au besoin exact
- Reste cohérent avec le ton des modules existants
- Si tu vois une amélioration évidente non demandée,
  signale-la en une phrase après ta réponse
- Si ambiguïté : pose UNE seule question de clarification
- Ne reformate JAMAIS en structure de module complet

🎙️ Podcast — Analyse approfondie

Génère un résumé audio "Analyse approfondie"
pour le module [N] — [Titre] uniquement.
Objectif : introduction avant lecture du module.
Durée cible : 5-7 minutes.

- Commence par l'accroche "Et si..." du module
- Alterne entre présentation du problème,
  analogie principale, 2-3 points clés en avant-goût,
  défi annoncé comme une promesse
- Termine : "Pour aller plus loin, retrouve
  le module complet juste en dessous"
- Ton dynamique et bienveillant
- Ne révèle pas tout — donne envie, ne remplace pas le cours

🎙️ Podcast — Briefing (court)

Génère un résumé audio "Briefing"
pour le module [N] — [Titre] uniquement.
Durée cible : 5-7 minutes. Ton : direct, coach, zéro blabla.

Structure :
· 30s : le problème que ce module résout
· 1min : l'analogie principale simplifiée
· 2min : les 3 points clés en avant-goût
· 1min : le mécanisme "pourquoi ça marche"
· 30s : le défi annoncé + invitation à lire le module

Ne révèle pas les outils ni les erreurs fréquentes.

☁️ Hébergement des fichiers

Cloudinary pour l'audio et les images

Pourquoi Cloudinary et pas Drive ?

Google Drive bloque la lecture directe des fichiers dans les navigateurs pour des raisons de sécurité. Cloudinary est conçu pour diffuser des médias — l'audio se lance instantanément, les images s'affichent sans délai.

Comment uploader sur Cloudinary

  • 1
    Va sur cloudinary.com → crée un compte gratuit (connexion avec Google recommandée)
  • 2
    Dans le dashboard → clique sur "Media Library"
  • 3
    Clique sur "Upload" → sélectionne ton fichier MP3/MP4 ou PNG
  • 4
    Une fois uploadé → clique sur le fichier → "Copy URL"
  • 5
    Colle ce lien dans le chat Claude avec ton texte de module
⚠️ Organisation recommandée Crée un dossier par module dans Cloudinary : Module-1, Module-2... pour retrouver facilement tes fichiers.
🚀 Déploiement Vercel

Mettre en ligne en 5 étapes

  • 1
    GitHub → crée un compte → nouveau dépôt "upscale-[sujet]" → coche "Add README"
  • 2
    Upload → "Add file" → "Upload files" → glisse ton fichier renommé en "index.html"
  • 3
    Vercel → vercel.com → "Sign up" avec GitHub → "Add New Project" → sélectionne le dépôt
  • 4
    Config → Framework Preset = "Other" · Root Directory = vide → "Deploy"
  • 5
    Lien → récupère ton URL type upscale-gtd.vercel.app → envoie à tes apprenants

Mettre à jour la webapp

✅ Procédure simple GitHub → ton dépôt → "Add file" → "Upload files" → glisse le nouveau index.html → "Commit changes". Vercel se met à jour automatiquement en 30 secondes.
